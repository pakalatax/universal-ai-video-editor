# Compatibility

| Host | Operation |
| --- | --- |
| Codex CLI | Install as skill or reference SKILL.md; execute Python in terminal |
| Claude Code | Install skill or load instructions; execute Python in terminal |
| Gemini CLI | Refer to SKILL.md via agent instructions; execute Python in terminal |
| DeepSeek or other model in coding agent | Agent needs local shell and filesystem permission |
| Browser-only ChatGPT/Claude/Gemini/DeepSeek | Planning only unless execution is connected |

No service-enforced limit on local renders. CPU, memory and storage are finite. FFmpeg must support libx264 and its libass subtitle filter. Telugu captions need a compatible system font. Loudness normalization does not remove noise. AI video generation and transcription are additional components and may incur quotas or costs.
